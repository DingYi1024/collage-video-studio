# Editorial proof demo

This deterministic example proves that one recursive composition can be re-directed for
landscape, portrait, and square delivery without flattening its editable layers.

```bash
python build_demo.py
```

The build compiles three director plans, checks safe zones and motion continuity, then renders
three MP4 files under `result/`. The example uses only local vector, text, chart, route, and
annotation primitives, so it is reproducible without paid providers.
