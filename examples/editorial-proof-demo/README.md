# Editorial proof demo

This deterministic example proves that one recursive composition can be re-directed for
landscape, portrait, and square delivery without flattening its editable layers.

```bash
python build_demo.py
```

The build compiles three director plans, resolves annotation collisions, checks safe zones and
motion continuity, then renders three MP4 files under `result/`. The example uses only local
vector, data-SVG, text, chart, route, timeline, and annotation primitives, so it is reproducible
without paid providers.

The same `composition.json` opens in the repository `workspace/` Remotion editor. Automated
semantic evidence for topology, mechanism order, exact chart values, and exact text is stored as
`result/semantic-proof-*.json`.
